# LemLib Figure-Eight Validation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace small-robot AUT3's 12-inch motion with a smooth, continuous, host-validated pure-pursuit figure-eight contained within two field tiles by two field tiles.

**Architecture:** A deterministic PowerShell generator produces a LemLib v0.5 path asset from a compact parametric figure-eight. A dependency-free configuration header holds the path's start pose and motion limits, a host test validates the generated geometry, and the existing `Actions::followPath` adapter supplies cancellation, motion-health, ownership, logging, and fail-closed behavior.

**Tech Stack:** C++17, PROS 4.2.2, LemLib 0.5.6, JerryIO/LemLib text assets, PowerShell, MinGW g++, GNU Make/ARM toolchain.

## Global Constraints

- Keep every path point within X = -22 through 22 inches and Y = 0 through 44 inches.
- Use one continuous forward `followPath` call with an 8-inch lookahead and 12-second timeout.
- Cap generated speed at 65, target 35 at crossover/tight curvature, and finish at no more than 20.
- Operate no mechanisms and change no Kevin, Park, Skills, fallback, or Shadow playback behavior.
- Big-robot execution remains unsupported and fail-closed.
- Stop with `pros::E_MOTOR_BRAKE_BRAKE` on success or failure.
- Restore `USING_BIG_ROBOT false` before the final commit.

```cpp
#include "aon/auton/figure-eight-validation.hpp"

#include <algorithm>
#include <cmath>
#include <cstdlib>
#include <fstream>
#include <iostream>
#include <sstream>
#include <string>
#include <vector>

#define CHECK(value) do { if (!(value)) { \
  std::cerr << #value << '\n'; std::exit(1); } } while (false)

struct Point {
  double x;
  double y;
  double speed;
};

int main() {
  using aon::auton::FigureEightValidation;
  CHECK(FigureEightValidation::startX == -20.0);
  CHECK(FigureEightValidation::startY == 22.0);
  CHECK(FigureEightValidation::startHeading == 0.0);
  CHECK(FigureEightValidation::lookahead == 8.0F);
  CHECK(FigureEightValidation::timeoutMs == 12000);
  CHECK(FigureEightValidation::maximumPathSpeed == 65);

  std::ifstream input("static/figure-eight.jerryio.txt");
  CHECK(input.is_open());
  std::vector<Point> points;
  bool foundTerminator = false;
  std::string line;
  while (std::getline(input, line)) {
    if (line == "endData") {
      foundTerminator = true;
      break;
    }
    std::replace(line.begin(), line.end(), ',', ' ');
    std::istringstream values(line);
    Point point{};
    CHECK(static_cast<bool>(values >> point.x >> point.y >> point.speed));
    points.push_back(point);
  }

  CHECK(foundTerminator);
  CHECK(points.size() >= 40);
  CHECK(points.front().x == FigureEightValidation::startX);
  CHECK(points.front().y == FigureEightValidation::startY);
  CHECK(points.front().speed <= 20.0);
  CHECK(points.back().speed <= 20.0);

  bool reachedLeft = false;
  bool reachedRight = false;
  bool wasInCenter = false;
  int centerEntries = 0;
  for (std::size_t index = 0; index < points.size(); ++index) {
    const Point& point = points[index];
    CHECK(point.x >= -22.0 && point.x <= 22.0);
    CHECK(point.y >= 0.0 && point.y <= 44.0);
    CHECK(point.speed >= 0.0 &&
          point.speed <= FigureEightValidation::maximumPathSpeed);
    reachedLeft = reachedLeft || point.x <= -12.0;
    reachedRight = reachedRight || point.x >= 12.0;
    const bool inCenter = std::abs(point.x) <= 1.5 &&
                          std::abs(point.y - 22.0) <= 1.5;
    if (inCenter && !wasInCenter) ++centerEntries;
    wasInCenter = inCenter;
    if (index != 0) {
      const double dx = point.x - points[index - 1].x;
      const double dy = point.y - points[index - 1].y;
      CHECK(std::hypot(dx, dy) <= 2.5);
    }
  }
  CHECK(reachedLeft);
  CHECK(reachedRight);
  CHECK(centerEntries >= 2);
  std::cout << "figure-eight path tests passed\n";
}
```

- [ ] **Step 4: Add the deterministic asset generator**

Create `tools/generate-figure-eight-path.ps1`:

```powershell
$ErrorActionPreference = 'Stop'
$culture = [System.Globalization.CultureInfo]::InvariantCulture
$steps = 120
$lines = [System.Collections.Generic.List[string]]::new()

for ($index = 0; $index -le $steps; ++$index) {
  $t = [Math]::PI + 2.0 * [Math]::PI * $index / $steps
  $x = 20.0 * [Math]::Cos($t)
  $y = 22.0 + 18.0 * [Math]::Sin(2.0 * $t)
  if ([Math]::Abs($x) -lt 0.0005) { $x = 0.0 }
  if ([Math]::Abs($y - 22.0) -lt 0.0005) { $y = 22.0 }

  $edge = [Math]::Min($index, $steps - $index)
  $rampSpeed = [Math]::Min(65.0, 20.0 + 4.5 * $edge)
  if ($index -eq $steps) {
    $speed = 0.0
  } elseif ([Math]::Abs($x) -le 4.0) {
    $speed = [Math]::Min($rampSpeed, 35.0)
  } elseif ([Math]::Abs($x) -ge 17.0) {
    $speed = [Math]::Min($rampSpeed, 40.0)
  } else {
    $speed = $rampSpeed
  }

  $lines.Add([string]::Format(
      $culture, "{0:F3}, {1:F3}, {2:F3}", $x, $y, $speed))
}

$lines.Add('endData')
$lines.Add('65')
$lines.Add('35')
$lines.Add('200')
$lines.Add('#PATH.JERRYIO-DATA {"appVersion":"0.11.0","format":"LemLib v0.5","name":"AON 2x2 Figure Eight","generator":"tools/generate-figure-eight-path.ps1","bounds":{"minX":-22,"maxX":22,"minY":0,"maxY":44}}')

$projectRoot = Split-Path -Parent $PSScriptRoot
$output = Join-Path $projectRoot 'static\figure-eight.jerryio.txt'
$lines | Set-Content -LiteralPath $output -Encoding ascii
Write-Output "Generated $output with $($steps + 1) points"
```

```cpp
int RunLemLibFigureEightValidation() {
  auto& routine = aon::auton::actions();

#if USING_BIG_ROBOT
  aon::auton::logStep(FigureEightValidation::name,
                      "unsupported big robot");
  routine.stop(pros::E_MOTOR_BRAKE_BRAKE);
  return 0;
#else
  aon::auton::logStep(FigureEightValidation::name, "start");
  routine.setPose(FigureEightValidation::startX,
                  FigureEightValidation::startY,
                  FigureEightValidation::startHeading);
  const auto result = routine.followPath(
      FigureEightValidation::name, figure_eight_jerryio_txt,
      FigureEightValidation::lookahead,
      FigureEightValidation::timeoutMs, true);
  routine.stop(pros::E_MOTOR_BRAKE_BRAKE);
  aon::auton::logStep(FigureEightValidation::name,
                      result.succeeded ? "finish" : "failed");
  return result.succeeded ? 1 : 0;
#endif
}
```
